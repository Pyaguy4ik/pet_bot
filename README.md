# ТЕХНИЧЕСКОЕ ЗАДАНИЕ

## Разработка Telegram-бота для управления здоровьем и лечением домашнего питомца (кота Папуш)

## Выполнил студент ЭФМО-02-25 Пягай Даниил Игоревич

---

### 1. Основание для разработки

Разработка Telegram-бота обусловлена необходимостью автоматизации процессов контроля за приёмом лекарств домашнего питомца, ведения медицинской истории (анализов, визитов к ветеринару) и предоставления своевременных напоминаний с учётом индивидуального графика лечения, разделённого на чётные и нечётные недели.

---

### 2. Назначение разработки

Создание программного комплекса для владельца кота по имени Папуш, обеспечивающего:
- Ежедневные напоминания о выдаче лекарств с учётом дня недели и чётности недели
- Управление расписанием визитов к ветеринару
- Хранение и сравнение результатов анализов
- Полный контроль над графиком лечения через Telegram-интерфейс

---

### 3. Цели разработки

- Создание удобного интерфейса для добавления, удаления и редактирования лекарств
- Реализация системы напоминаний с поддержкой чётных/нечётных недель
- Разработка модуля для управления визитами к ветеринару
- Создание системы хранения и просмотра анализов по датам
- Обеспечение круглосуточной работы бота на удалённом сервере

---

### 4. Требования к функциональным характеристикам

#### 4.1. Управление лекарствами

- Добавление нового лекарства с указанием: названия, времени приёма, дозировки, дней недели, принадлежности к чётной/нечётной неделе (all/odd/even)
- Удаление существующего лекарства по названию
- Редактирование любого параметра лекарства
- Включение/отключение лекарства без удаления
- Просмотр полного списка лекарств с группировкой по неделям

#### 4.2. Система напоминаний

- Автоматические уведомления в Telegram в указанное время
- Учёт дня недели (пн, вт, ср, чт, пт, сб, вс)
- Учёт чётности недели (1 неделя — нечётная, 2 неделя — чётная)
- Ручное переключение режима определения чётности недели
- Ежедневный отчёт в 08:00 с планом на день

#### 4.3. Управление визитами к ветеринару

- Добавление визита с указанием даты, времени, описания и адреса
- Удаление визита по дате
- Просмотр ближайшего предстоящего визита

#### 4.4. Управление анализами

- Добавление результатов анализов за определённую дату (показатель=значение)
- Просмотр анализов по дате
- Удаление анализов за дату
- Список всех дат с сохранёнными анализами

---

### 5. Требования к надёжности

## 2. Функциональное назначение
Программа предназначена для автоматизации процессов контроля за лечением домашнего питомца и решает следующие задачи:

Напоминание о выдаче лекарств в определённое время с учётом дня недели и чётности недели

Ведение расписания визитов к ветеринару

Хранение и просмотр результатов анализов

Полное управление графиком лечения через Telegram-команды

Функциональные ограничения: бот рассчитан на одного пользователя (владельца кота Папуш).

## 3. Описание логической структуры
Архитектура: монолитная с разделением на модули.
```
Telegram User
    ↓ (сообщение)
Telegram Bot API
    ↓ (webhook/polling)
main.go (точка входа, запуск бота)
    ↓
handlers.go (обработка команд, валидация)
    ↓
storage.go (бизнес-логика, работа с данными)
    ↓
data/pet_data.json (хранение)
    ↑
scheduler.go (фоновый планировщик напоминаний)
```
Модули:

main.go - точка входа, инициализация бота и маршрутов

config.go - хранение токена Telegram-бота

handlers.go - обработчики всех команд (/start, /daily, /addmed, /editmed, /addvet, /addanalysis и др.)

storage.go - структуры данных (Medicine, VetVisit, Analysis, PetData), функции загрузки/сохранения, логика определения чётности недели

scheduler.go - фоновый планировщик для отправки напоминаний

## 5. Вызов и загрузка
Запуск на сервере:

```
cd ~/pet_bot
go build -o petbot
nohup ./petbot > bot.log 2>&1 &
```
Запуск через systemd (автозапуск при загрузке):
```
sudo nano /etc/systemd/system/petbot.service

[Unit]
Description=Pet Bot for Papush
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/root/pet_bot
ExecStart=/root/pet_bot/petbot
Restart=always
RestartSec=10

[Install]
WantedBy=multi-user.target
```
```
sudo systemctl daemon-reload
sudo systemctl enable petbot
sudo systemctl start petbot
```

## Точки входа (команды в Telegram):
### Команды
- /start	Приветствие и список команд
- /daily	План на сегодня
- /week	Текущая неделя (чётная/нечётная)
- /setweek odd/even/auto	Ручное переключение недель
- /medlist	Список всех лекарств
- /addmed	Добавить лекарство
- /delmed	Удалить лекарство
- /editmed	Редактировать лекарство
- /togglem ed	Вкл/выкл лекарство
- /nextvet	Ближайший визит
- /addvet	Добавить визит
- /delvet	Удалить визит
- /addanalysis	Добавить анализы
- /getanalysis	Показать анализы
- /delanalysis	Удалить анализы
- /listanalysis	Список дат с анализами

## 6. Форматы команд
### Лекарства
#### Добавление:
```
/addmed Название|Время(ЧЧ:ММ)|Дозировка|Дни(пн,вт,ср)|Неделя(all/odd/even)

Пример:
/addmed Креон|10:55|1/2 капсулы|пн,вт,ср,чт,пт,сб,вс|all
/addmed Чистка зубов|22:00|обработка|пн,ср,пт|odd
```
#### Удаление:
``` 
/delmed Креон
```
#### Редактирование:
```
/editmed "Название"|поле=значение

Доступные поля: name, time, dosage, days, week, active

Примеры:
/editmed Креон|time=14:00
/editmed Креон|days=пн,ср,пт
/editmed Креон|week=odd
/editmed Креон|active=false
```
#### Включение/выключение:
```
/togglem ed Креон
```
#### Визиты:
```
/addvet 2026-05-10 14:30 Осмотр ул.Ленина 5
/delvet 2026-05-10
```
#### Анализы:
```
/addanalysis 2026-04-01 лейкоциты=8.2 глюкоза=5.1
/getanalysis 2026-04-01
/delanalysis 2026-04-01
/listanalysis
```

#### Управление неделями:
```
/setweek odd    # принудительно нечётная (1 неделя)
/setweek even   # принудительно чётная (2 неделя)
/setweek auto   # автоматический режим (по ISO)
```
